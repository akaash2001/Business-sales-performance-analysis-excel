# Business Sales & Performance Analysis using Microsoft Excel

## Project Overview
This project analyzes business sales data using Microsoft Excel to identify sales trends, product performance, regional profitability, and category performance.

The objective is to transform raw sales data into meaningful business insights that support better business decisions.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Formulas
- Conditional Formatting
- Dashboard Creation

## Dataset
- 1,000 sales records
- 11 original data columns
- Sales, profit, product, category, customer, and regional information

## Data Validation
- Checked for blank cells in the original dataset.
- Checked Order IDs for duplicates.
- Verified calculated sales against recorded sales.
- Verified calculated profit against recorded profit.
- All 1,000 sales and profit records matched the calculations.

## Business Analysis
1. Product Performance Analysis
2. Regional Profit Analysis
3. Monthly Sales Analysis
4. Category Performance Analysis

## Key Findings
- Top-selling product: Laptop
- Highest-profit region: North
- Highest-sales month: March
- Highest-sales category: Electronics
